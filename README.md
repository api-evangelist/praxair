# Praxair (praxair)

Praxair was an American multinational industrial gases company that merged with Linde AG in 2018 to form Linde plc. Praxair operations in the United States now operate as Linde. This repository captures the APIs, developer tools, and machine-readable API artifacts for Praxair.
